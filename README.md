# Dating App Flutter Prototype

Flutter 기반 데이팅 앱 프론트엔드 프로토타입입니다.

## 포함 화면

- 온보딩 없이 바로 진입하는 탐색 홈
- 매칭 후보 카드 스와이프/좋아요/패스 UI
- 오늘의 추천, 관심사 필터, 호감도 정보
- 매칭 목록
- 채팅 목록 및 샘플 대화 화면
- 내 프로필/선호 조건/앱 설정 화면

## 실행

Flutter SDK가 설치된 환경에서:

```bash
flutter create .
flutter pub get
flutter run
```

이미 Android/iOS/Web 플랫폼 폴더가 있는 Flutter 프로젝트에 `lib/main.dart`와 `pubspec.yaml`만 합치는 경우에는 `flutter create .` 단계는 생략해도 됩니다.

현재 작업 환경에는 Flutter/Dart CLI가 설치되어 있지 않아 로컬 빌드 검증은 수행하지 못했습니다.
